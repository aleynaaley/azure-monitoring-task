# Azure Monitoring Task

---

## 🇬🇧 English

### About

This repository contains an Azure Monitor research and hands-on study carried out during my Cloud Engineering internship.

The study focuses on understanding how monitoring data is collected, stored, analyzed, and used for monitoring Azure resources, with practical examples using an Azure Linux Virtual Machine.

### Topics Covered

* Azure Monitor
* Monitoring data: Metrics, Logs, and Traces
* Log Analytics Workspace
* Azure Monitor Workspace
* Diagnostic Settings
* Azure Monitor Agent (AMA)
* Data Collection Rules (DCR)
* Data Collection Rule Associations (DCRA)
* Linux Syslog collection
* Virtual Machine monitoring
* OpenTelemetry-based guest monitoring
* Kusto Query Language (KQL)
* Azure Monitor Alerts

### Hands-on Work

During the study, an Azure Linux Virtual Machine was used to:

* Observe Azure platform metrics such as CPU utilization
* Collect Linux Syslog data
* Configure AMA, DCR, and DCRA
* Store collected logs in a Log Analytics Workspace
* Explore guest OS performance monitoring
* Work with Azure Monitor Workspace and metrics
* Query monitoring data using KQL
* Create a CPU-based Azure Monitor alert

The research was documented using Obsidian and exported as a PDF.

### Repository Contents

* `Azure-Monitor.pdf` — Completed Azure Monitoring documentation
* `Azure-Monitoring.zip` — Obsidian-based documentation and related files
